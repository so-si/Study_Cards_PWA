# Study Cards PWA

## このリポジトリは何のためのもの？

このリポジトリは、Google スプレッドシートに保存している Study Cards のデータを、iPhone などから見やすく学習するための **PWA（ホーム画面に追加できるWebアプリ）** です。

目的は、普段はオンラインで最新カードを使いながら、飛行機の中など通信できない場面では、事前に保存したカードでそのまま勉強できるようにすることです。

この公開リポジトリ自体には、Google スプレッドシートの中身や `Code.gs` は置きません。

大まかな構成は次のとおりです。

```text
Study_Cards_PWA（この公開リポジトリ）
        ↓
Google Apps Script の Web API
        ↓
Google Spreadsheet
  ├─ Cards
  ├─ History
  └─ Daily
```

- GitHub Pages側：画面・オフライン利用の仕組み
- Google Apps Script側：スプレッドシートの読み書き
- Google Spreadsheet側：カード本体、学習履歴、日次集計

という役割分担です。

---

## 普段の使い方

### オンラインで使う場合

GitHub Pages版をオンライン状態で開き、必要に応じて「オンラインで最新版を読む」を押します。

これにより、Google Apps Script経由でスプレッドシートの最新カードを読み込みます。

GitHub版を普段の学習用として使っても問題ありません。

従来のGoogle Apps Script版の画面を使い続けても構いません。

---

## 飛行機など、オフラインで使いたい場合

通信できなくなる前に、GitHub Pages版を開いて、

**「オフライン用に保存」**

を押します。

すると、その時点の最新カード一式が端末内に保存されます。

画面には、

- 何問保存済みか
- いつ保存したか

が表示されます。

その後は機内モードでも、保存済みカードを使って学習できます。

### 大事な点

オフライン用カードは、自動で毎回更新されるわけではありません。

新しいカードを追加したり、TSVを更新した場合は、次の飛行機搭乗前などにもう一度 **「オフライン用に保存」** を押してください。

---

## ○△×の学習履歴について

学習中に押した ○・△・× は、オンライン時にはGoogle Apps Script経由でスプレッドシートの履歴へ保存されます。

オフライン時は、いったん端末内に未同期履歴として保存されます。

オンライン状態に戻ってGitHub版を開くと、未同期履歴があれば自動で同期を試みます。

そのため、飛行機で勉強した後は、着陸後などに一度GitHub版をオンライン状態で開いておくと安心です。

---

## 接続キーについて

Google Apps Script側には `API_TOKEN` を設定しています。

GitHubにはこの接続キーを保存しません。

GitHub版を初めて使う端末では、画面の

**「接続キーを設定・変更」**

から接続キーを入力します。

入力した接続キーは、その端末のブラウザ内（localStorage）に保存されます。

### 注意

接続キーそのものはREADMEやソースコードに書かないでください。

接続キーを変更した場合は、各端末でも新しいキーを設定し直します。

---

# ファイルごとの役割

## `index.html`

GitHub版PWAの中心となるファイルです。

主に次の内容が入っています。

- 画面デザイン
- 文字サイズ
- 科目・大分野の表示
- 学習開始
- 問題表示
- 穴あき規範 → 全文規範の切替
- ○△×
- オフライン用カードの保存
- 未同期履歴の保存・同期
- Google Apps Script APIとの通信

### こんな変更をするときに触る

- 文字を大きくしたい
- ボタンの位置を変えたい
- 科目の並び順を変えたい
- 大分野の表示方法を変えたい
- 学習画面の見た目を変えたい
- オフライン保存の動きを変えたい
- ○△×の処理を変えたい

GitHub版の画面や操作を変える場合は、まずこのファイルを見るのが基本です。

---

## `config.js`

Google Apps ScriptのWebアプリURLを設定するファイルです。

通常、頻繁に触る必要はありません。

### 変更が必要になる例

Google Apps Scriptを再デプロイして、Webアプリの `/exec` URLが変わった場合です。

そのときだけ、新しいGAS URLに差し替えます。

### 注意

`API_TOKEN` はここに書きません。

接続キーは端末側に保存する方針です。

---

## `service-worker.js`

GitHub Pages版そのものをオフラインでも起動できるようにするためのファイルです。

カードデータそのものとは別に、

- `index.html`
- `config.js`
- `manifest.json`

など、アプリ本体のファイルをブラウザにキャッシュします。

### こんな変更をするときに触る

- PWAのキャッシュ対象を変えたい
- 更新したのに古い画面が出続ける問題を直したい
- PWAの更新方法を変えたい

### とても重要

`index.html`などを大きく更新した場合、古いPWAキャッシュが残ることがあります。

その場合は `CACHE_NAME` のバージョンを、たとえば

```js
study-cards-pwa-v2
```

のように上げると、古いキャッシュを捨てて新しい画面へ更新しやすくなります。

---

## `manifest.json`

iPhoneやスマートフォンで「ホーム画面に追加」したときの、アプリらしい表示に関する設定です。

主に、

- アプリ名
- 短い表示名
- 起動URL
- 表示方法
- 背景色
- テーマ色

などを指定します。

### こんな変更をするときに触る

- ホーム画面上のアプリ名を変えたい
- PWAの表示方式を変えたい
- アイコン等を将来追加したい

普段のカード学習機能を変更するだけなら、通常ここは触りません。

---

# Google Apps Script側のファイルとの関係

この公開リポジトリとは別に、Google Apps Script側には主に次の2つがあります。

## GAS側 `Code.gs`

バックエンドです。

主に、

- Cardsシートからカード取得
- Historyへの学習結果保存
- Daily集計
- API_TOKENの確認
- APIリクエスト処理

を担当します。

### こんな変更をするときに触る

- スプレッドシートの読み方を変える
- Historyの保存方法を変える
- Daily集計を変える
- APIの処理を追加する
- セキュリティ処理を変更する

**GitHub版を使い続ける限り `Code.gs` は必要です。削除しません。**

---

## GAS側 `Index.html`

従来のGoogle Apps Script版の学習画面です。

Google Apps Script版も引き続き使う場合は残しておきます。

### こんな変更をするときに触る

- Google Apps Script版の文字サイズを変えたい
- Google Apps Script版の画面構成を変えたい
- Google Apps Script版だけに機能追加したい

### 注意

GitHub版の `index.html` と、GAS版の `Index.html` は別物です。

片方を変更しても、もう片方には自動反映されません。

---

| やりたいこと | 変更する場所 |
|---|---|
| カード内容を追加・修正 | TSV / Spreadsheet |
| Google Spreadsheetの読み書きを変える | GAS `Code.gs` |
| History / Dailyの処理を変える | GAS `Code.gs` |
| API認証を変える | GAS `Code.gs` |
| GAS版の画面を変える | GAS `Index.html` |
| GitHub版の画面を変える | `Study_Cards_PWA/index.html` |
| GitHub版の文字サイズを変える | `Study_Cards_PWA/index.html` |

| オフライン保存方法を変える | `Study_Cards_PWA/index.html` |

| ホーム画面上のPWA設定を変える | `manifest.json` |
| GASのWebアプリURLが変わった | `config.js` |

# よくある更新の流れ

## 1. カード内容だけ更新した場合

例：TSVに新しい問題を追加した場合

1. SpreadsheetのCardsを更新
2. GAS側コードは通常変更不要
3. オンライン版では最新カードを読み直す
4. オフラインでも使いたい場合は「オフライン用に保存」をもう一度押す

これだけです。

---

## 2. GitHub版の見た目を変更した場合

例：問題文をもっと大きくする場合

1. `Study_Cards_PWA/index.html` を変更
2. GitHubへ反映
3. 必要に応じて `service-worker.js` のキャッシュバージョンも上げる
4. GitHub PagesをSafariで再読み込み

ホーム画面版に古い画面が残る場合は、一度SafariからGitHub Pages URLを開き直します。

---

## 3. GASの処理を変更した場合

例：Historyへの保存方式を変える場合

1. GASの `Code.gs` を変更
2. Apps Scriptで保存
3. Webアプリとして新バージョンをデプロイ
4. `/exec` URLが同じならGitHub側は通常変更不要
5. URLが変わった場合だけ `config.js` を更新

---

# privateの `Study_Cards` リポジトリについて

別途存在する `Study_Cards` リポジトリは、privateのまま残します。

主な用途は、

- 開発用
- 元コードの保管
- GASコードのバックアップ
- 変更前の状態へ戻したい場合の保険

です。

公開用の `Study_Cards_PWA` と役割を分けておくことで、GASのソースやSpreadsheetに関する情報を公開リポジトリへ不用意に置かずに済みます。

---

# セキュリティ上の注意

このリポジトリは公開されています。

そのため、次のものは原則としてコミットしません。

- `API_TOKEN`
- Googleアカウントの認証情報
- パスワード
- 秘密鍵
- Spreadsheetの中身を丸ごと書き出したファイル
- 個人情報

GASのWebアプリURLは接続先として `config.js` に置くことがありますが、API_TOKENは端末内保存とし、公開コードには書かない方針です。

---

# 迷ったとき

基本的には次の3つだけ覚えておけば大丈夫です。

1. **カード内容を変える → Spreadsheet / TSV**
2. **Google側の処理を変える → `Code.gs`**
3. **GitHub版の見た目・操作を変える → `Study_Cards_PWA/index.html`**

PWAの更新後に古い画面が残る場合だけ、`service-worker.js` のキャッシュも確認します。
